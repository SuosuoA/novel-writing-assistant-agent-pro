### 4.2 核心数据流

**保存流程**:
```
用户操作 → GUI方法 → agent._plugin.xxx()
         → 更新 self._outline_content
         → _auto_save_outline_changes()
         → ProjectManager.sync_module_data('outline', data)
         → JSON序列化写入项目文件
```

**加载流程**:
```
项目文件 → JSON反序列化 → ProjectManager.load_project()
        → _restore_project_data_to_ui()
        → 检查 _outline_tree 是否已创建
        ├── 已创建 → 直接更新树形结构
        └── 未创建 → 标记 _pending_outline_chapters
                   → _create_outline_content() 时延迟更新
```

**拖拽排序流程**:
```
鼠标按下 → _on_outline_drag_start() [记录起始位置]
鼠标移动 → _on_outline_drag_motion() [检测目标, >5px激活]
鼠标释放 → _on_outline_drag_end() [确认框 → plugin.reorder_chapters()
                                           → 更新树形结构 → 自动保存]
```

## 五、踩坑经验

### 5.1 P0级教训：tag_bind vs bind

**问题**: 为修复拖拽功能，将 `bind()` 改为 `tag_bind("all", ...)`，导致整个大纲页面无法渲染。

**根因**: `ttk.Treeview` 是标准Tkinter组件，使用 `bind()` 方法。`tag_bind()` 是 Canvas 和 Text 组件的专有方法。

**修复**: 改回 `self._outline_tree.bind(event, handler)`

**规则**: **永远不要假设某个组件拥有某个API。不确定时查阅官方文档或测试验证。**

### 5.2 章节序号重复

**现象**: "第1章: 第1章 标题"

**根因**: 树形显示固定拼接"第X章:"前缀，但插件的 `title` 字段已经是纯章节标题（不含"第X章"），或原始数据本身就带"第X章"。

**修复**: 在三处显示逻辑中增加格式检测:
```python
if title.startswith('第') and '章' in title:
    node_text = f"{title} | ..."
else:
    node_text = f"第{i+1}章: {title} | ..."
```

### 5.3 拖拽距离判断

**问题**: 点击选择章节也弹出拖拽移动确认框

**根因**: `<ButtonPress-1>` 和 `<ButtonRelease-1>` 在任何点击时都会触发

**修复**: 
- 记录 `start_y` 坐标
- 设置 `min_drag_distance = 3` 像素阈值
- 只有移动超过阈值才激活 `dragging=True`
- `drag_end` 时检查 `dragging` 是否为True

### 5.4 延迟更新机制

**问题**: 打开项目后大纲页面空白

**根因**: Tkinter Notebook 的标签页是首次切换时才创建（延迟创建）。项目打开时如果用户在大纲页面以外的标签页，`_outline_tree` 还不存在。

**修复**: 
```python
# 恢复数据时：
self._pending_outline_chapters = chapters_data

# 创建页面时：
if hasattr(self, '_pending_outline_chapters'):
    self._update_outline_tree_from_chapters(self._pending_outline_chapters)
```

### 5.5 插件返回值格式

**问题**: `_on_outline_parse_complete()` 中获取 `result.data.get("outline_content")` 返回空字符串

**根因**: Agent.execute() 返回的 `result.data` 本身就是完整的大纲对象字典，不需要再取子字段

**修复**: `self._outline_content = result.data` （直接赋值整个对象）
