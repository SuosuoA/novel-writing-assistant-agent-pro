# Desktop Control UX测试完整指南

> **创建日期**: 2026-04-13  
> **技能版本**: Desktop Control v1.0  
> **适用场景**: 用户体验测试、界面可用性评估、自动化操作测试

---

## 🎯 核心能力

### 1. 屏幕感知
- **屏幕尺寸**: 2560×1440 (2K分辨率)
- **截图功能**: 全屏/窗口/区域截图
- **图像识别**: 定位UI元素位置
- **OCR文本识别**: 读取屏幕文本内容

### 2. 操作控制
- **鼠标**: 移动、点击、双击、右键、拖拽、滚动
- **键盘**: 打字、快捷键、组合键、功能键
- **应用**: 打开、聚焦、切换窗口

### 3. 交互测试
- **弹窗确认**: 模拟用户决策
- **输入框**: 收集用户反馈
- **警告提示**: 关键操作确认

---

## 📋 UX测试标准工作流程

### 第一步：环境感知（先观察再行动）

```bash
# 1. 获取屏幕尺寸
uvx desktop-agent screen size

# 2. 列出当前窗口
uvx desktop-agent app list

# 3. 获取鼠标当前位置
uvx desktop-agent mouse position
```

**输出示例**:
```json
{
  "success": true,
  "data": {
    "size": {"width": 2560, "height": 1440}
  }
}
```

---

### 第二步：打开目标应用

```bash
# 打开应用
uvx desktop-agent app open <应用名>

# 聚焦窗口
uvx desktop-agent app focus "<窗口标题>"

# 验证窗口已打开
uvx desktop-agent app list
```

**实际案例**:
```bash
# Windows打开记事本
uvx desktop-agent app open notepad

# 聚焦窗口
uvx desktop-agent app focus "Untitled - Notepad"
```

---

### 第三步：截图分析界面

#### 3.1 全屏截图
```bash
uvx desktop-agent screen screenshot full_screen.png
```

#### 3.2 窗口截图（推荐）
```bash
# 截取特定窗口
uvx desktop-agent screen screenshot window.png --window "Google Chrome"

# 截取当前活动窗口
uvx desktop-agent screen screenshot active.png --active
```

#### 3.3 区域截图
```bash
# 截取指定区域 (x,y,width,height)
uvx desktop-agent screen screenshot region.png --region "100,200,400,300"
```

---

### 第四步：定位UI元素

#### 4.1 图像识别定位
```bash
# 定位按钮位置
uvx desktop-agent screen locate-center button.png --confidence 0.8

# 输出: {"center_x": 125, "center_y": 215}
```

#### 4.2 OCR文本定位
```bash
# 定位文本位置
uvx desktop-agent screen locate-text-coordinates "Save" --active

# 读取所有文本
uvx desktop-agent screen read-all-text --active
```

---

### 第五步：模拟用户操作

#### 5.1 鼠标点击
```bash
# 移动到指定位置
uvx desktop-agent mouse move 960 540 --duration 0.5

# 点击
uvx desktop-agent mouse click 300 200

# 双击
uvx desktop-agent mouse double-click 300 200

# 右键
uvx desktop-agent mouse right-click 300 200

# 拖拽
uvx desktop-agent mouse drag 100 200 500 400 --duration 0.5

# 滚动
uvx desktop-agent mouse scroll -5  # 向下滚动5格
```

#### 5.2 键盘输入
```bash
# 打字
uvx desktop-agent keyboard write "Hello World" --interval 0.05

# 快捷键
uvx desktop-agent keyboard hotkey "ctrl,c"  # 复制
uvx desktop-agent keyboard hotkey "ctrl,v"  # 粘贴
uvx desktop-agent keyboard hotkey "ctrl,s"  # 保存

# 单键
uvx desktop-agent keyboard press enter
uvx desktop-agent keyboard press tab
```

---

### 第六步：收集测试反馈

#### 6.1 弹窗确认
```bash
uvx desktop-agent message confirm "操作是否成功？" --title "测试反馈"
```

#### 6.2 输入框收集
```bash
uvx desktop-agent message prompt "请描述您的体验：" --title "UX反馈"
```

## 🎮 实战案例：测试Novel Writing Assistant

### 场景：测试"开始创作"功能

```bash
# 1. 打开应用
uvx desktop-agent app open "Novel Writing Assistant-Agent Pro"

# 2. 聚焦窗口
uvx desktop-agent app focus "Novel Writing Assistant - Agent Pro"

# 3. 截图初始界面

uvx desktop-agent message prompt "请评价此次操作的流畅度（1-5分）："
```

## ⚠️ 安全注意事项

### 1. 失效保护机制
- **PyAutoGUI Fail-Safe**: 快速移动鼠标到屏幕左上角可中止所有操作
- **建议**: 测试前先确认失效保护已启用

### 2. 用户确认
```bash
# 危险操作前必须确认
uvx desktop-agent message confirm "此操作将删除所有数据，是否继续？" --title "警告"
```

### 3. 坐标验证
```bash
# 点击前验证坐标在屏幕内
uvx desktop-agent screen on-screen 1500 900
```

## 📈 性能优化建议

### 1. 减少截图范围
```bash
# ❌ 慢：全屏截图
uvx desktop-agent screen screenshot full.png

# ✅ 快：窗口截图
uvx desktop-agent screen screenshot window.png --active
```

### 2. 批量键盘输入
```bash
# ❌ 慢：多次输入
uvx desktop-agent keyboard write "Hello"
uvx desktop-agent keyboard write " World"

# ✅ 快：一次输入
uvx desktop-agent keyboard write "Hello World"
```

### 3. 使用快捷键代替鼠标
```bash
# ❌ 慢：鼠标导航菜单
uvx desktop-agent mouse click 50 30
uvx desktop-agent mouse click 60 80

# ✅ 快：快捷键
uvx desktop-agent keyboard hotkey "ctrl,s"
```

## 🎯 最佳实践

### 1. 观察优先原则
**永远先了解当前状态，再执行操作！**
```bash
# 正确流程
uvx desktop-agent screen size       # 了解屏幕尺寸
uvx desktop-agent app list          # 了解当前窗口
uvx desktop-agent mouse position    # 了解鼠标位置
# 然后再执行操作
```

### 2. 错误处理模式
```bash
# 窗口未找到时的处理
uvx desktop-agent app focus "Chrome"  # 失败
uvx desktop-agent app list            # 查看实际窗口名
# 调整为正确名称
uvx desktop-agent app focus "Google Chrome"
```

### 3. 图像定位调整
```bash
# 降低置信度匹配
uvx desktop-agent screen locate button.png --confidence 0.7  # 先尝试0.9失败则降低
```
