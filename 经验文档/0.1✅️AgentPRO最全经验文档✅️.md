#### 专家模式完整7步生成流程（V1.49.36）

> **设计目标**: 专家模式实现"越用越聪明、越用越懂用户、生成文章越来越符合预期"的持续学习闭环。

```
┌─────────────────────────────────────────────────────────────┐
│              专家模式7步迭代生成流程                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step1: 数据打包                                             │
│    世界观+风格+大纲+人物+知识库+技巧                          │
│    +上下文(前N章)+字数要求+[本章完]标记                      │
│    +【历史经验回读】ExpertMemory→避免重复问题                │
│                    ↓                                        │
│  Step2: API请求 → 接收文章                                  │
│    _call_base_generator() → novel-generator-v3             │
│                    ↓                                        │
│  Step3: 九维度评分                                          │
│    _evaluate_expert() → 总分+9维度分+修改方案               │
│    +【本章完】强制检查(缺失自动补充)                        │
│                    ↓                                        │
│  Step4-5: 不达标? → 带反馈重试(循环≤max_iterations)        │
│    _build_iteration_feedback() → 结构化反馈文本            │
│    feedback注入到下一轮请求的大纲内容中                     │
│    达标? YES→Step6  NO→继续循环                             │
│                    ↓                                        │
│  Step6: 输出最佳结果                                        │
│    GenerationResult(validation_scores + metadata)          │
│    metadata含: total_iterations/is_passing/best_score       │
│                    ↓                                        │
│  Step7: 经验沉淀到Claw记忆(mem9)                            │
│    _store_to_memory() → ExpertMemory                       │
│    L1热记忆(当前会话) + L2文件持久化                       │
│    下次生成Step1时通过retrieve_similar_issues()回读         │
│                                                             │
│  ★ 闭环: Step7存储 → 下次Step1回读 → 越用越聪明           │
└─────────────────────────────────────────────────────────────┘
```

**核心代码位置**:
- `plugins/expert-novel-v1/plugin.py` → `generate()` 方法（主循环）
- `plugins/expert-novel-v1/plugin.py` → `_build_iteration_feedback()` （反馈构建）
- `plugins/expert-novel-v1/plugin.py` → `_enhance_request()` （历史经验回读）
- `plugins/expert-novel-v1/memory.py` → `ExpertMemory` 类（记忆存储与检索）

> **保护规则**: 修改前必须经架构评审，保持向后兼容性
