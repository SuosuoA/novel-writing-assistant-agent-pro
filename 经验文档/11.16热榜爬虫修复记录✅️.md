### 1.1 缓存验证修复（2026-04-05）

**问题**: 缓存时间戳字段不一致导致验证失败
**根因**: `save_ranking_data()` 保存 `timestamp` 字段，但 `_is_cache_valid()` 检查 `datetime` 字段
**影响**: 缓存总是被认为无效，每次都重新爬取或返回默认数据

**修复内容**:
```python
# 修复前
if not cache_data or 'datetime' not in cache_data:
    return False

# 修复后（V1.1）
time_str = cache_data.get('datetime') or cache_data.get('timestamp')
if not time_str:
    return False
```

**验证**: ✅ 缓存验证正常，真实数据显示

### 1.2 同步爬取逻辑恢复（2026-04-05）

**问题**: 用户反馈热榜显示预设数据而非真实数据
**根因**: 之前为优化启动速度，将缓存不存在时的行为改为"返回默认数据+后台异步爬取"
**影响**: 用户看到的是预设数据

**修复内容**:
```python
# 修复前（异步爬取）
if not cached_data:
    raw_data = self._data_manager.get_default_data()
    self._start_background_crawl()  # 后台爬取，用户看到默认数据

# 修复后（恢复同步逻辑）
if not cached_data:
    raw_data = self._refresh_rankings(force_update=True)  # 同步爬取真实数据
```

**验证**: ✅ 显示真实爬取数据，热榜页面延迟加载不影响启动速度

## 二、热榜数据源说明

### 2.1 榜单网站

| 网站 | 端 | URL | 数据类型 |
|------|-----|-----|----------|
| 番茄小说 | 移动端 | `fanqienovel.com` | 首页API（周榜、男频、女频、更新榜） |
| 晋江文学城 | 移动端 | `m.jjwxc.net/rank/naturalmore/5` | 月度/季度排行榜 |
| 起点中文网 | 移动端 | `m.qidian.com/rank/hotsales/` | 热销榜、阅读指数榜 |

### 2.2 数据字段

**书籍数据**:
- `title`: 书名
- `author`: 作者
- `category`: 分类（自动推断）
- `heat`: 热度/字数
- `source`: 来源网站
- `url`: 书籍链接
- `is_real`: 是否真实数据

**作家数据**:
- `name`: 作家名
- `author_id`: 作家ID
- `works`: 代表作
- `works_count`: 作品数量
- `fans`: 粉丝数

## 三、爬虫架构

### 3.1 核心方法

| 方法名 | 功能 |
|--------|------|
| `crawl_fanqie_hot()` | 番茄小说热榜爬取 |
| `crawl_jinjiang_hot()` | 晋江文学城热榜爬取 |
| `crawl_jinjiang_authors()` | 晋江作家榜爬取 |
| `crawl_qidian_hot()` | 起点中文网热榜爬取 |
| `crawl_all_sources()` | 聚合爬取所有源 |

### 3.2 降级策略

1. **移动端优先**: 优先使用移动端API（数据更完整）
2. **PC端降级**: 移动端失败时自动降级到PC端
3. **Mock数据兜底**: 所有爬虫失败时返回预设数据
