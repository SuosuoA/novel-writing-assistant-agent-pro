## 二、根因分析

### 2.1 第一轮问题定位（V1.49.20）

**问题链路**：
```
expert_selector.load_expert_plugin()
  ↓ 注册插件
plugin_registry.register()
  ↓ 【缺失】initialize()调用
  ✗ plugin.initialize(context) 未调用
  ↓ 导致
plugin._plugin_registry = None
```

**根因**: EventBus等服务通过`register()`按类型注册，不是`register_service()`按名称注册。应该用全局函数获取。

**错误代码**:
```python
ServiceLocator.get_service("event_bus")  # 错误：按名称查询
```

**正确代码**:
```python
get_event_bus()  # 正确：使用全局函数
```

### 2.2 第二轮问题定位（V1.49.21）

**问题链路**：
```
MainWindow.__init__()
  ↓ 调用
_load_plugins()
  ↓ 【只读取plugin.json显示】
  ✗ 未调用PluginLoader.load_all()
  ↓ 导致
PluginRegistry._plugins = {}  # 空字典
  ↓ 导致
expert-novel-v1._load_dependencies()
  ↓ 查询
plugin_registry.get_plugin("novel-generator-v3")
  ↓ 条件
plugin_info.state == PluginState.ACTIVE  # 找不到插件
  ↓ 最终
依赖插件未加载
```

**根因**: `_load_plugins()` 方法（V1.48.15）只扫描文件显示，没有调用 `PluginLoader` 真正加载插件到 Registry。

**错误实现**（V1.48.15）:
```python
def _load_plugins(self):
    # 只读取plugin.json显示
    with open(plugin_json, "r") as f:
        data = json.load(f)
    # 插件数据存到self._plugin_data
    self._plugin_data[item_id] = {...}
    # ❌ 没有调用PluginLoader.load_all()
```

**正确实现**（V1.49.21）:
```python
def _load_plugins(self):
    # 1. 先真正加载插件到Registry
    self._load_plugins_from_filesystem()
    
    # 2. 从Registry获取真实状态显示
    registry = get_plugin_registry()
    all_plugins = registry.get_all_plugins()
    
    # 3. 显示真实状态
    for plugin_id, plugin_info in all_plugins.items():
        state_text = state_map.get(plugin_info.state)
        # ...
```

## 三、修复方案

### 3.1 第一轮修复（V1.49.20）

**修复位置**: `gui/expert_selector.py`

**修复内容**: 添加PluginContext创建和initialize()调用

```python
# 修复前（缺失）
# 只注册插件，不初始化

# 修复后
from core.plugin_interface import PluginContext
from core.event_bus import get_event_bus
from core.config_manager import get_config_manager
from core.service_locator import get_service_locator

context = PluginContext(
    event_bus=get_event_bus(),
    service_locator=get_service_locator(),
    config_manager=get_config_manager(),
    plugin_registry=self.plugin_registry
)

# 调用initialize

```

**关键发现**:
1. EventBus等核心服务通过全局函数获取（`get_event_bus()`）
2. 不应从ServiceLocator按名称获取（event_bus是按类型注册）
3. 参考`plugin_loader.py:517-522`标准实现

### 3.2 第二轮修复（V1.49.21）

**修复位置**: `gui_main.py:14348` (`_load_plugins()`方法)

**修复内容**: 调用PluginLoader真正加载插件到Registry

```python
def _load_plugins(self) -> None:
    """加载插件列表 - V1.49.21修复版"""
    
    # 1. 先真正加载插件到Registry
    try:
        self._load_plugins_from_filesystem()
    except Exception as e:
        logger.warning(f"PluginLoader加载失败，回退到简单扫描: {e}")
    
    # 2. 从Registry获取插件信息（优先）
    try:
        registry = get_plugin_registry()
        all_plugins = registry.get_all_plugins()
        
        if all_plugins:
            # 从Registry显示真实状态
            for plugin_id, plugin_info in all_plugins.items():
                state_text = state_map.get(plugin_info.state)
                # ...
            return
    except Exception as e:
        logger.warning(f"从Registry获取插件失败，回退到文件扫描: {e}")
    
    # 3. 回退：直接从文件系统加载（V1.48.15逻辑）
    # ...
```

**修复原理**:
1. 调用`_load_plugins_from_filesystem()` → 调用`PluginLoader.load_all()`
2. `PluginLoader.load_all()` → 加载插件并注册到Registry
3. 从Registry获取真实状态（active/loaded/error）
4. 如果失败，回退到文件扫描（兼容性）

### 5.1 服务获取方式

| 按类型注册 | `get(ServiceType)` 或全局函数 | `get_event_bus()` |
| 按名称注册 | `get_service("name")` | `get_service("project_manager")` |

### 5.2 插件加载流程

**正确流程**:
```
1. PluginLoader.discover_plugins()  # 发现插件
2. PluginLoader.load_all()          # 加载所有插件
   ↓ 每个插件
   ├─ import_plugin()               # 动态导入
   ├─ registry.register()           # 注册到Registry

```
1. 扫描plugins目录
2. 读取plugin.json
3. 显示在UI
❌ 没有真正加载到Registry
```

```python
# V1.49.20修复：初始化插件（传递context）

try:
    from core.plugin_interface import PluginContext
    from core.event_bus import get_event_bus
    from core.config_manager import get_config_manager
    from core.service_locator import get_service_locator

### 3.3 关键要点

1. **使用全局函数获取核心服务**

   - `get_config_manager()` - ConfigManager单例
   - `get_service_locator()` - ServiceLocator单例

2. **不要从ServiceLocator获取**
   - EventBus按类型注册，不能用`get_service("event_bus")`
   - 应该用`get(EventBus)`或直接使用全局函数

3. **参考标准实现**
   - `plugin_loader.py`是标准实现

## 六、关键经验总结

### 6.1 架构理解

1. **服务注册方式**
   - `register(service_type, instance)` - 按类型注册
   - `register_service(name, instance)` - 按名称注册

2. **服务获取方式**
   - 按类型注册 → `get(ServiceType)` 或全局函数
   - 按名称注册 → `get_service("name")`

3. **插件初始化流程**
   - 注册(register) → 初始化(initialize) → 激活(activate)

### 6.2 修复流程改进

1. **必须先查阅设计文档**（已写入核心规则）

### 6.3 踩坑记录
