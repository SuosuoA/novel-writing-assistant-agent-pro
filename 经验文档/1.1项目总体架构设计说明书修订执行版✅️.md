## 一、架构总览

### 1.1 架构愿景

Novel Writing Assistant-Agent Pro 采用**微内核架构**，核心系统仅提供基础调度服务（EventBus、PluginRegistry、ServiceLocator、ConfigManager），所有业务功能以插件形式存在。

### 1.2 架构分层图

```
┌─────────────────────────────────────────────────────────────────┐
│                         用户界面层 (Tkinter)                      │
│  主窗口 → 工作台(Notebook) → 设置面板 → 插件管理                    │
└─────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────┐
│                      应用层 (MasterAgent)                        │
│  Thinker(思考) → Optimizer(优化) → Validator(验证) → Planner(规划)│
└─────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
┌───────────────────────┐ ┌───────────────┐ ┌───────────────────────┐
│   微内核核心 (Kernel)   │ │  插件系统      │ │   服务层 (Services)    │
│  EventBus             │ │ PluginRegistry│ │   AI API服务           │
│  PluginRegistry       │ │ Loader        │ │   文件服务             │

└───────────────────────┘ └───────────────┘ └───────────────────────┘
```

### 1.3 核心设计原则

#### 微内核原则
核心系统仅提供最基本的服务（插件调度、事件分发、依赖管理），所有业务功能通过插件实现。

#### 榫卯式集成
插件与核心通过标准接口"咬合"，接口定义严格，实现灵活。

#### 事件驱动
插件间通过EventBus通信，解耦依赖。

## 二、微内核核心引擎

### 2.1 事件总线 (EventBus)

#### 核心职责

插件间发布-订阅通信的核心机制，实现插件解耦。**必须保证线程安全**。

#### 关键接口

```python
# core/event_bus.py
from typing import Dict, List, Any, Callable, Optional
from dataclasses import dataclass
from abc import ABC, abstractmethod
import threading
import time
from uuid import uuid4
from concurrent.futures import ThreadPoolExecutor
from datetime import datetime, timezone

@dataclass
class Event:
    """事件对象"""
    type: str                      # 事件类型
    data: Any                      # 事件数据（支持复杂对象）
    source: Optional[str] = None    # 事件来源
    timestamp: Optional[float] = None  # 时间戳
    event_id: Optional[str] = None     # 事件ID

    def __post_init__(self):
        if self.timestamp is None:
            self.timestamp = datetime.now(timezone.utc).timestamp()
        if self.event_id is None:
            self.event_id = f"evt-{uuid4().hex[:8]}"

class EventBus:
    """事件总线 - 线程安全，真异步实现"""
    
    def __init__(self, max_workers: int = 10):
        self._handlers: Dict[str, List[Dict[str, Any]]] = {}
        self._lock = threading.RLock()
        self._subscriptions: Dict[str, str] = {}
        self._executor = ThreadPoolExecutor(max_workers=max_workers)
        self._dead_letter_queue: List[Dict] = []
    
    def subscribe(self, event_type: str, handler: Callable, 
                   handler_id: str = None) -> str:
        """订阅事件，返回订阅ID"""
        if handler_id is None:
            handler_id = f"handler-{uuid4().hex[:8]}"
        
        with self._lock:
            if event_type not in self._handlers:
                self._handlers[event_type] = []
            
            self._handlers[event_type].append({
                "id": handler_id,
                "handler": handler,
            })
            self._subscriptions[handler_id] = event_type
        
        return handler_id
    
    def unsubscribe(self, subscription_id: str) -> bool:
        """取消订阅"""
        with self._lock:
            event_type = self._subscriptions.get(subscription_id)
            if not event_type:
                return False
            
            handlers = self._handlers.get(event_type, [])
            self._handlers[event_type] = [
                h for h in handlers if h["id"] != subscription_id
            ]
            
            del self._subscriptions[subscription_id]
            return True
    
    def publish(self, event_type: str, data: Any, source: str = None):
        """发布事件 - 真异步，使用线程池执行"""
        event = Event(type=event_type, data=data, source=source)
        
        with self._lock:
            handlers = list(self._handlers.get(event_type, []))
        
        # 提交到线程池异步执行
        for handler_info in handlers:
            self._executor.submit(self._safe_invoke, handler_info, event)
    
    def _safe_invoke(self, handler_info: Dict, event: Event):
        """安全调用handler，带异常处理和超时控制"""
        handler_id = handler_info["id"]
        handler = handler_info["handler"]
        
        try:
            handler(event)
        except Exception as e:
            # 记录到日志，不传播异常
            print(f"事件处理失败 {event.type} [handler={handler_id}]: {e}")
            # 添加到死信队列
            self._dead_letter_queue.append({
                "event": event,
                "handler_id": handler_id,
                "error": str(e),
                "timestamp": time.time()
            })
    
    def publish_sync(self, event_type: str, data: Any,
                     timeout: float = 5.0) -> List[Any]:
        """同步发布事件，等待所有处理器返回结果"""
        event = Event(type=event_type, data=data)
        results = []
        
        with self._lock:
            handlers = list(self._handlers.get(event_type, []))
        
        for handler_info in handlers:
            try:
                result = handler_info["handler"](event)
                results.append(result)
            except Exception as e:
                print(f"事件处理失败 {event_type}: {e}")
        
        return results
```

#### 使用示例

```python
# 订阅事件

    print(f"生成开始: {event.data['chapter_title']}")

event_bus.subscribe(EVENT_GENERATION_STARTED, on_generation_started)

# 发布事件（真异步，立即返回）

    "chapter_title": "第一章",
    "word_count_target": 2000

# 同步发布（主线程中可安全操作UI）
```

### 2.2 插件注册表 (PluginRegistry)

#### 核心职责

管理所有已加载的插件，提供查询、状态转换和插槽绑定功能。

#### 关键接口

```python
# core/plugin_registry.py
from typing import Dict, List, Optional
from enum import Enum
import threading

class PluginState(Enum):
    """插件状态"""
    LOADED = "loaded"      # 已加载（初始化完成）
    ACTIVE = "active"      # 已激活（可执行）
    ERROR = "error"        # 错误状态
    UNLOADING = "unloading"  # 卸载中

class PluginRegistry:
    """插件注册表 - 含完整状态管理"""
    
    def __init__(self):
        self._plugins: Dict[str, BasePlugin] = {}
        self._states: Dict[str, PluginState] = {}
        self._slots: Dict[str, Optional[str]] = {}
        self._lock = threading.RLock()
        self._error_counts: Dict[str, int] = {}
        self._max_retries = 3
    
    def register(self, plugin: BasePlugin) -> bool:
        """注册插件"""
        plugin_id = plugin.metadata.id
        
        with self._lock:
            if plugin_id in self._plugins:
                return False
            
            self._plugins[plugin_id] = plugin
            self._states[plugin_id] = PluginState.LOADED
            self._error_counts[plugin_id] = 0
            return True
    
    def unregister(self, plugin_id: str) -> bool:
        """注销插件"""
        with self._lock:
            if plugin_id not in self._plugins:
                return False
            
            # 解绑插槽
            for slot_id, pid in self._slots.items():
                if pid == plugin_id:
                    self._slots[slot_id] = None
            
            del self._plugins[plugin_id]
            del self._states[plugin_id]
            del self._error_counts[plugin_id]
            return True
    
    def get_plugin(self, plugin_id: str) -> Optional[BasePlugin]:
        """获取插件实例"""
        return self._plugins.get(plugin_id)
    
    def get_plugins_by_type(self, plugin_type: PluginType) -> List[BasePlugin]:
        """按类型获取插件"""
        return [
            plugin for plugin in self._plugins.values()
            if plugin.metadata.plugin_type == plugin_type
        ]
    
    def get_state(self, plugin_id: str) -> Optional[PluginState]:
        """获取插件当前状态"""
        return self._states.get(plugin_id)
    
    def activate(self, plugin_id: str) -> bool:
        """激活插件（LOADED → ACTIVE）"""
        with self._lock:
            if plugin_id not in self._plugins:
                return False
            self._states[plugin_id] = PluginState.ACTIVE
            return True
    
    def deactivate(self, plugin_id: str) -> bool:
        """停用插件（ACTIVE → LOADED）"""
        with self._lock:
            if plugin_id not in self._plugins:
                return False
            self._states[plugin_id] = PluginState.LOADED
            return True
    
    def set_error(self, plugin_id: str, error: Exception) -> bool:
        """设置插件错误状态"""
        with self._lock:
            if plugin_id not in self._plugins:
                return False
            self._states[plugin_id] = PluginState.ERROR
            self._error_counts[plugin_id] = self._error_counts.get(plugin_id, 0) + 1
            return True
    
    def recover(self, plugin_id: str) -> bool:
        """从ERROR状态恢复插件（ERROR → LOADED）"""
        with self._lock:
            if plugin_id not in self._plugins:
                return False
            if self._states.get(plugin_id) != PluginState.ERROR:
                return False
            
            # 检查重试次数
            count = self._error_counts.get(plugin_id, 0)
            if count >= self._max_retries:
                return False  # 超过最大重试次数
            
            plugin = self._plugins[plugin_id]
            try:
                success = plugin.initialize(self._context)
                if success:
                    self._states[plugin_id] = PluginState.LOADED
                    return True
            except Exception as e:
                self._error_counts[plugin_id] = count + 1
            
            return False
```

**状态转换图**:
```
LOADED → ACTIVE        (activate成功)
ACTIVE → LOADED        (deactivate成功)
LOADED → ERROR         (initialize异常)
ACTIVE → ERROR         (execute连续失败)
ERROR → LOADED         (recover成功)
LOADED → UNLOADING     (卸载请求)
```

### 2.3 服务定位器 (ServiceLocator)

#### 核心职责

提供核心服务的依赖注入，支持循环依赖检测。

```python
# core/service_locator.py
from typing import Dict, Type, Any, Set, Optional
import threading

class CircularDependencyError(Exception):
    """循环依赖异常"""
    pass

class ServiceLocator:
    """服务定位器 - 含循环依赖检测"""
    
    def __init__(self):
        self._services: Dict[Type, Any] = {}
        self._lock = threading.RLock()
    
    def register_service(self, service_type: Type, instance: Any):
        """注册服务实例"""
        with self._lock:
            self._services[service_type] = instance
            
            # 在锁内检测循环依赖
            if hasattr(instance, 'dependencies'):
                if self._check_circular_dependency_locked(service_type):
                    del self._services[service_type]
                    raise CircularDependencyError(
                        f"检测到循环依赖，涉及服务: {service_type.__name__}"
                    )
    
    def get_service(self, service_type: Type) -> Optional[Any]:
        """获取服务实例"""
        return self._services.get(service_type)
    
    def has_service(self, service_type: Type) -> bool:
        """检查服务是否存在"""
        return service_type in self._services
```

### 3.2 插件接口标准

#### BasePlugin接口

```python
@dataclass
class PluginMetadata:
    """插件元数据"""
    id: str                          # 唯一标识符（如：outline-parser-v3）
    name: str                        # 显示名称
    version: str                     # 版本号（语义化版本）
    description: str                 # 描述
    author: str                      # 作者
    plugin_type: PluginType          # 插件类型
    api_version: str = "1.0"         # API版本
    priority: int = 100              # 加载优先级（越小越先）
    enabled: bool = True             # 是否启用
    dependencies: List[str] = field(default_factory=list)  # 依赖插件ID列表
    conflicts: List[str] = field(default_factory=list)     # 冲突插件ID列表
    permissions: List[str] = field(default_factory=list)   # 所需权限
    min_platform_version: str = "6.0.0"  # 最低平台版本

class BasePlugin(ABC):
    """插件基类 - 所有插件必须继承"""

    @classmethod
    @abstractmethod
    def get_metadata(cls) -> PluginMetadata:
        """获取插件元数据"""
        pass

    @abstractmethod
    def initialize(self, context: PluginContext) -> bool:
        """初始化插件"""
        pass

    @abstractmethod
    def execute(self, *args, **kwargs) -> Any:
        """执行插件核心功能"""
        pass

    @abstractmethod
    def shutdown(self) -> bool:
        """关闭插件"""
        pass
```

## 四、Agent深度集成

### 4.1 MasterAgent架构

**专家Agent清单**:

| Agent | 职责 | 关键能力 |
|-------|------|----------|
| Thinker | 深度思考推理 | CoT（思维链）、ToT（思维树） |
| Optimizer | 迭代优化 | 反馈驱动、自我修正 |
| Validator | 质量验证 | 多维度评分、规则检查 |
| Planner | 任务规划 | 目标分解、依赖分析 |

### 4.2 Agent协作模式

- **链式协作**: Planner → Thinker → Optimizer → Validator → Planner（循环）
- **树状协作**: Planner分发任务到多个Thinker，汇总后Optimizer优化
- **网状协作**: Planner与Validator持续验证，多个Thinker并行思考

### 4.3 Agent执行约束

| Agent | 超时 | 重试 | 降级策略 |
|-------|------|------|----------|
| Thinker | 30s | 1次 | 跳过CoT，直接推理 |
| Optimizer | 20s | 1次 | 返回原始生成结果 |
| Validator | 15s | 0次 | 返回默认评分0.5 |
| Planner | 10s | 0次 | 使用上一次计划 |

### 8.2 Tkinter线程安全规范

- 需要更新UI时，使用`widget.after()`调度到主线程

```python
def _on_generation_completed(self, event: Event):
    # 【Tkinter线程安全】使用after()调度到主线程
    def update_ui():
        result = event.data.get("result")
        self.text_area.insert("1.0", result["content"])
    
    self.root.after(0, update_ui)
```

### 8.4 V1.49.36完整7步生成流程（专家模式核心）

#### 设计初衷

专家模式的生成流程遵循以下7步闭环设计，目标是实现"越用越聪明、越用越懂用户、生成文章越来越符合预期"：

| 步骤 | 名称 | 核心动作 | 输出 |
|------|------|----------|------|
| Step 1 | 数据打包 | 整合世界观/风格/大纲/人物/知识库/技巧/上下文/字数要求/【本章完】标记 + 历史经验回读 | enhanced_request |
| Step 2 | API请求 | 发送请求给LLM，接收文章初稿 | content |
| Step 3 | 九维度评分 | 总分+各维度分(9项)+切实可行的修改方案 | ExpertEvaluation |
| Step 4-5 | 迭代优化 | 不达标→带反馈再次请求（循环≤max_iterations次）| 每轮反馈文本 |
| Step 6 | 达标输出 | 分数达标输出成果 / 达上限输出最佳结果 | GenerationResult |
| Step 7 | 经验沉淀 | 总结经验输入Claw化记忆(mem9)，用于自我优化 | ExpertMemory持久化 |

**关键特性：**
- 历史经验在Step1注入（`_enhance_request`读取ExpertMemory），避免"每次从零开始"
- 反馈在Step4-5循环中逐轮细化（`_build_iteration_feedback`构建结构化反馈）
- Step7存储的经验会在下次生成的Step1自动加载，形成持续学习闭环

---

**默认模式数据流**:
```
GUI._on_start_generation()
  → service.submit_async_generation()
    → PipelineOrchestrator.execute()
      → novel-generator-v3.generate_chapter()
        → quality-validator-v1.validate_with_weights()
          → WeightedValidationResult(total_weighted_score, passed, suggestions)
        → iterative-generator-v2.generate_with_iteration()
          → validation_fn → 桥接评分 → 【本章完】检查 → 循环迭代（≤5次）
        → final_stats（含weighted_total_score、passed）
      → validation阶段 → 智能跳过
    → GUI._on_generation_complete()
      → 读取stats.weighted_total_score、stats.passed
      → QualityValidatorPlugin.get_dimension_display_map()获取维度映射
      → 显示评分详情
```

**专家模式数据流（V1.49.36完整版 - 含迭代循环和记忆闭环）**:
```
GUI._start_expert_generation()
  → ExpertSelector.load_expert_plugin() → PluginRegistry.load_plugin_runtime()
  → ExpertPlugin.generate(request)

    ===== Step 1: 数据打包（_enhance_request）=====
    → 整合世界观/风格/大纲/人物/知识库/技巧/上下文/字数
    → 【新增】历史经验回读: retrieve_evaluation() + retrieve_similar_issues()
    → enhanced.historical_evaluation = 历史评分
    → enhanced.historical_solutions = 历史优化方案

    ===== Step 2-5: 迭代循环（for iteration in range(max_iterations)）=====
    → 第1轮: _call_base_generator(request) → 接收content
              ↓
           _evaluate_expert(content) → 九维度评分
              ↓
           【本章完】缺失? → 自动补充 → 重新评分
              ↓
           score >= threshold? → YES → 跳到Step6
                                NO  → 继续↓
              ↓
           _generate_optimization(evaluation) → OptimizationSuggestion
              ↓
           _build_iteration_feedback(iter, score, eval, opt) → 结构化反馈文本
              ↓
           将feedback追加到大纲内容 → 注入下一轮请求
              ↓
           第2~N轮: 重复上述过程（含上轮feedback）

    ===== Step 6: 输出最佳结果 =====
    → _create_result(best_content, best_evaluation)
    → metadata附加: total_iterations / is_passing / best_score / iteration_scores

    ===== Step 7: 经验沉淀到Claw记忆 =====
    → _store_to_memory(best_eval, optimization, request)
    → ExpertMemory.store_evaluation() → L1热记忆 + L2文件持久化
    → ExpertMemory.store_optimization() → 下次生成时可通过retrieve_similar_issues()回读

  → GUI._on_expert_generation_complete()
    → 读取result.validation_scores.total_score
    → 读取metadata.total_iterations（显示迭代轮次）
    → QualityValidatorPlugin.get_dimension_display_map()获取维度映射
    → 显示评分详情 + 优化建议
```
