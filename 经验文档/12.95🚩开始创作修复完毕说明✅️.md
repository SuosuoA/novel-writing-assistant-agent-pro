```python
def build_generation_context(self, chapter_number, target_words, raw_data,
                              selected_knowledge_bases=None, 
                              selected_writing_techniques=None,
                              expert_config=None):
    context = {
        'chapter_number': chapter_number,
        'target_words': target_words,
        'knowledge_categories': selected_knowledge_bases or [],
        'writing_techniques': selected_writing_techniques or [],
        'expert_config': expert_config,
    }
    
    # 1. 大纲内容（格式化章节列表为文本 + 后备策略）
    context['outline_content'] = self._format_outline(raw_data)
    context['chapter_outline'] = self._format_chapter_outline(raw_data, chapter_number)
    
    # 2. 风格档案（8维度→生成器格式 转换 + 模板格式处理）
    context['style_profile'] = self._format_style_profile(raw_data)
    
    # 3. 人物设定（列表→字典 转换）
    context['characters'] = self._format_characters(raw_data)
    
    # 4. 世界观（直接传递，无业务逻辑）
    context['worldview'] = raw_data.get('worldview', {})
    
    # 5. 前文内容（3级回退策略）
    context['previous_chapter_text'] = self._get_previous_chapters(chapter_number, raw_data)
    
    return context
```

#### 人设（_format_characters）

- **转换逻辑**：`list` → `dict{name: char_dict}`（匹配GenerationRequest.character_profiles要求）

```python
def _format_characters(self, raw_data):
    character_list = raw_data.get('character_data', [])
    character_dict = {}
    for char in character_list:
        if isinstance(char, dict):
            name = char.get('name', '未命名')
            character_dict[name] = char
    return character_dict
```

**关键注意**：`GenerationDataService._format_characters()` 返回 `{name: dict}` 格式，但 `ExpertValidator` 期望 `[{name: "xxx", ...}]` 列表格式。这个格式差异在 `ExpertPlugin._enhance_request()` 中做了二次转换（V6.3修复）。

```python
def _enhance_request(self, request):
    enhanced = request  # 不修改原始请求
    
    # ===== 世界观数据 =====
    # 优先级：worldview_config(新) > worldview_reference(旧)
    worldview_data = getattr(request, 'worldview_config', None) or getattr(request, 'worldview_reference', None)
    if isinstance(worldview_data, dict): enhanced.worldview_data = worldview_data
    elif isinstance(worldview_data, str): enhanced.worldview_data = self._load_worldview(worldview_data)
    
    # ===== 人物数据（V6.3修复：dict→list转换）=====
    char_data = getattr(request, 'character_profiles', None) or getattr(request, 'character_references', None)
    if isinstance(char_data, list): enhanced.character_data = char_data
    elif isinstance(char_data, dict):
        # {name: profile} → [{name: "xxx", ...}]
        char_list = []
        for char_name, char_profile in char_data.items():
            if isinstance(char_profile, dict):
                if 'name' not in char_profile: char_profile['name'] = char_name
                char_list.append(char_profile)
            else:
                char_list.append({'name': char_name, 'value': char_profile})
        enhanced.character_data = char_list
    
    # V6.2修复：过滤人物，只保留章节相关人物
    # 从chapter_outline中匹配人物名，至少保留1个
    
    # ===== 大纲数据 =====
    # 优先级：chapter_outline(单章) > outline(完整)
    chapter_outline = getattr(request, 'chapter_outline', None)
    outline_data = getattr(request, 'outline', None) or getattr(request, 'outline_reference', None)
    # 如果chapter_outline存在：outline_data = {"content": chapter_outline}
    # 如果是JSON字符串或文件路径：解析/加载
    
    # ===== 风格数据 =====
    style_data = getattr(request, 'style_profile', None) or getattr(request, 'style_reference', None)
    # dict直接用，str从文件加载
    
    # ===== 知识库和写作技巧 =====
    enhanced.knowledge_base = self._load_knowledge_base(selected_categories=...)
    enhanced.writing_techniques = self._load_writing_techniques(selected_techniques=...)
    
    # ===== 前文上下文 =====
    prev_chapters = getattr(request, 'previous_chapter_text', None) or getattr(request, 'previous_chapters', None)
    enhanced.previous_chapters = prev_chapters if isinstance(prev_chapters, list) else [prev_chapters]
    
    # ===== 历史经验回读（V1.49.36核心特性）=====
    if self._expert_memory:
        prev_eval = self._expert_memory.retrieve_evaluation(chapter_id)
        if prev_eval: enhanced.historical_evaluation = prev_eval
        similar_solutions = self._expert_memory.retrieve_similar_issues(common_issues, top_k=3)
        if similar_solutions: enhanced.historical_solutions = similar_solutions
    
    # ===== 目标字数 =====
    enhanced.word_count_target = getattr(request, 'word_count', None) or getattr(request, 'word_count_target', None)
    
    return enhanced

        "previous_chapters": previous_chapters or [],
        "target_words": target_words,
        "_data_source": {  # V6.2新增：标记哪些维度是用户配置的

            "characters_is_user_provided": has_original_characters,

        }
    }

```

#### Step 4-5: 迭代优化

```python
for iteration in range(max_iterations):
    # Step 2: 生成
    base_result = self._call_base_generator(enhanced_request)
    content = self._extract_content(base_result)
    
    # Step 3: 评分
    expert_evaluation = self._evaluate_expert(content, enhanced_request)
    current_score = expert_evaluation.total_score
    
    # 【本章完】检查
    if '【本章完】' not in content:
        content = self._add_chapter_end_marker(content)
        expert_evaluation = self._evaluate_expert(content, enhanced_request)
    
    # 达标判断
    if current_score >= quality_threshold and has_chapter_end:
        break  # 跳到Step 6
    
    # 不达标：构建反馈
    optimization = self._generate_optimization(expert_evaluation)
    last_feedback = self._build_iteration_feedback(iteration, current_score, expert_evaluation, optimization)
    
    # 反馈注入到下次请求
    if isinstance(enhanced_request.outline_data, dict):
        enhanced_request.outline_data['content'] += "\n\n" + last_feedback
    enhanced_request.optimization_feedback = last_feedback
```

### 5.2 评分流程（evaluate方法）

```python
def evaluate(self, content, context):
    # 第零步：强制检查【本章完】标记（缺失→返回0分，一票否决）
    if not self._check_chapter_end_marker(content):
        return self._create_failed_evaluation("章节缺少【本章完】标记")
    
    # 第一步：基础维度评分
    scores["worldview"] = self._evaluate_worldview(content, worldview_data, is_user_provided=...)
    scores["character"] = self._evaluate_character(content, characters_data, is_user_provided=...)
    scores["outline"] = self._evaluate_outline(content, outline_data, is_user_provided=...)
    scores["style"] = self._evaluate_style(content, style_data, is_user_provided=...)
    scores["word_count"] = self._evaluate_word_count(content, target_words)
    
    # 第二步：扩展维度评分
    scores["knowledge"] = self._evaluate_knowledge_base(content, knowledge_data, is_loaded=...)
    scores["writing_technique"] = self._evaluate_writing_technique(content, techniques)
    scores["context_coherence"] = self._evaluate_context_continuation(content, previous_chapters)
    scores["ai_feeling"] = self._evaluate_ai_sense(content)
    
    # 第三步：生成分析
    analysis = self._generate_analysis(scores, content, context)
    
    # 第四步：计算加权总分
    total_score = sum(scores.get(k, 0.5) * self.expert_weights.get(k, 0.1) for k in self.expert_weights)
    
    # 第五步：识别问题和优势
    issues = self._identify_issues(scores, analysis)
    strengths = self._identify_strengths(scores, analysis)
    
    return ExpertEvaluation(total_score, dimension_scores=scores, analysis, issues, strengths)
```

### 5.3 各维度评分规则详解

#### 世界观一致性（12%）- _evaluate_worldview

- **用户未配置** → 中性分 0.85
- **数据流断裂**（用户配置了但数据为空）→ ValueError
- **结构化格式**（有elements字段）→ 检查元素名在内容中的匹配率
- **通用格式**（无elements字段）→ 提取2-6字中文关键词，检查匹配率
- **规则违反** → 每违反1条扣0.1分
- **分数区间**: 0.0 ~ 1.0

#### 人设一致性（19%）- _evaluate_character

- **用户未配置** → 中性分 0.85
- **数据流断裂** → ValueError
- **V10.1三层检测架构**（V10.0重写，V10.1基线提升）：
  - 第1层：关键词匹配（权重30%）——基线**0.65**（从0.60提升），性格关键词每词+0.25上限，对话风格+0.10
  - 第2层：行为语义检测（权重50%，V10.0新增）——4信号：
    - 动作描写（人物名附近动词模式）
    - 心理/内心描写（心里/想着/觉得等）
    - 带修饰的角色对话（动作/神态+对话）
    - 性格倾向语义扩展（坚韧→坚持/咬牙等近义词映射）
  - 第3层：存在度和交互密度（权重20%）——人物名在文本中的频率和分布
    - 8次以上→1.0，5次→0.85，3次→0.70，1次→0.55
  - **最终分** = L1*0.3 + L2*0.5 + L3*0.2，最低基线 **0.68**（V10.1从0.62提升）
- **取平均值**：所有出场人物的评分取平均
- **无人名出现** → 0.25

#### 大纲符合度（13%）- _evaluate_outline

- **用户未配置** → 中性分 0.85
- **数据流断裂** → ValueError
- **结构化格式**（有key_events字段）→ 检查事件在内容中的匹配率
- **纯文本格式**（content字段）→ 提取2-6字中文关键词（最多30个），检查匹配率
- **分数区间**: 0.5 ~ 1.0（最低0.5保底）

#### 风格一致性（19%）- _evaluate_style

- **用户未配置** → 中性分 0.85
- **数据流断裂** → ValueError
- **V10.1三层检测架构**（V10.0重写，V10.1基线提升）：
  - 第1层：关键词匹配（权重40%）——支持 keywords/style_tags/writing_characteristics/prompt_suggestions 多种字段
    - 有标签时基线0.62 + 匹配率*0.40（上限0.40）
    - 无标签时基线0.66
  - 第2层：语义特征检测（权重40%，V10.0新增）——5维度：描写丰富度/对话质量/内心独白/节奏变化/风格倾向匹配
  - 第3层：文本质量信号（权重20%，V10.0新增）——段落分布/修辞手法/短句堆砌检测
  - **最终分** = L1*0.4 + L2*0.4 + L3*0.2，最低基线 **0.72**（V10.1从0.68提升）
- **句式多样性加分**：句子长度方差>20 → +0.2（额外bonus）
- **分数区间**: 0.72 ~ 1.0

#### 知识库引用（8%）- _evaluate_knowledge_base

- **未加载** → 中性分 0.85
- **数据流断裂** → ValueError
- **遍历各分类**：检查知识点的keywords在内容中的匹配
- **匹配率** = matched_items / total_items
- **分数区间**: 0.5 ~ 1.0（最低0.5保底）

#### 写作技巧（8%）- _evaluate_writing_technique（三层验证）

**三层验证架构**（V1.5.0版本）：

| 层级 | 权重 | 方法 | 说明 |
|------|:----:|------|------|
| L1 知识库技巧验证 | 40% | _verify_technique_application() | 检查知识库选定的写作技巧是否在文本中应用 |
| L2 fiction-writing专业评估 | 40% | _evaluate_fiction_quality() | 5维度专业评估：结构/人物深度/展示vs告知/节奏/世界观构建 |
| L3 TechniqueMonitor深度检测 | 20% | _evaluate_technique_monitor() | 6大分类58个技巧的结构化深度检测 |

**L1 知识库技巧验证**：
- 从知识库加载的技巧数据中提取keywords，检查匹配率
- 技巧标题直接出现在内容中也算应用
- 无技巧数据时降级为内置7大类+质量信号检测
- 基础分0.5 + 关键词匹配率*0.35 + 标题提及*0.15

**L2 fiction-writing专业评估**：
- 需要SkillManager和fiction-writing技能可用
- 5维度加权：结构(15%) + 人物深度(20%) + 展示vs告知(30%) + 节奏(25%) + 世界观(10%)
- V1.4.0修复：将完整验证器context透传给skill，解决空数据返回中性分的问题
- 不可用时返回0.5中性分

**L3 TechniqueMonitor深度检测**：
- 需要SkillManager和TechniqueMonitorResult可用
- 基于6大分类58个技巧的结构化检测
- 基础分 + 高置信度技巧加分(每技巧+0.02, 最多+0.10) + 分类覆盖加分(3类+0.03, 4类+0.05)
- 不可用时返回0.5中性分

**最终得分**: `technique_score * 0.40 + quality_score * 0.40 + monitor_score * 0.20`

#### 字数符合性（8%）- _evaluate_word_count

- **计算方式**: 实际字数/目标字数（去除换行和空格后）
- **评分规则**:
  - 95%~110%: 1.0（完美达标）
  - 80%~95%: 0.8
  - 60%~80%: 0.6
  - 超过110%: max(0.4, 1.0-(ratio-1.10)*0.5)
  - 60%以下: max(0.3, ratio)
- **目标字数≤0**: 0.5

#### 上下文衔接（8%）- _evaluate_context_continuation

- **第一章无上文** → 合法，返回0.85（首章不应因无前文扣分）
- **非第一章无上文** → plugin层负责校验
- **有前文时**：提取前文最后章节的2-4字中文关键词(最多20个)，检查匹配率
- **分数区间**: 0.5 ~ 1.0

#### AI感检测（5%）- _evaluate_ai_sense

- **优先使用humanizer技能**：检测18种AI写作模式
  - 内容模式：过度强调重要性、模糊引用、大纲式结构
  - 语言模式：AI词汇、系词回避、负面对仗
  - 风格模式：破折号滥用、粗体滥用、表情符号
  - 沟通模式：协作痕迹、知识截止声明、谄媚语气
  - 返回 `result.naturalness` (0~1，越高越自然)
- **降级方案**：内置8种AI模式正则检测
  - 匹配1个模式 → +0.15 AI感
  - naturalness = 1.0 - min(1.0, ai_score)
