### 4.2 核心数据流

**深度学习流程**:
```
用户点击 → _on_style_learn()
        → Step1: plugin.analyze(file) → 8维度解析
        → Step2: plugin.deep_analyze(result) → AI增强
        → _on_style_unified_complete() → 合并展示
        → _add_style_to_tree() → Treeview更新
        → _auto_save_style_changes() → 自动保存
```

**项目打开恢复流程**:
```
项目文件 → JSON反序列化 → _restore_style_ui()
       → 检查控件就绪
       ├── 未就绪 → _pending_style_restore = True
       │         → 切换页面时 _do_pending_style_restore()
       └── 已就绪 → 直接更新Text+Treeview
```

**导出/导入流程**:
```
导出 → _on_style_export() → json.dump(profile)
     → 包含dimensions字段（插件生成）

导入 → _on_style_load_profile() → json.load()
     → StyleLearnerPlugin.ensure_dimensions() ← 兼容旧JSON
     → _add_style_to_tree() → 显示评分
```

## 五、踩坑经验

### 5.1 P0级教训：目录名连字符导入问题

**问题**: `No module named 'plugins.style_learner_v5'`

**根因**: 插件目录名`style-learner-v5`含连字符，Python模块语法不支持

**修复**: 使用`importlib.util`动态导入
```python
import importlib.util
spec = importlib.util.spec_from_file_location(
    "style_learner_plugin",
    os.path.join(os.path.dirname(__file__), "plugins", "style-learner-v5", "plugin.py")
)
style_module = importlib.util.module_from_spec(spec)
spec.loader.exec_module(style_module)
```

**规则**: **插件目录命名避免连字符，或使用动态导入**

### 5.2 延迟创建机制缺失

**现象**: 打开项目后风格界面空白

**根因**: 
1. 标签页延迟创建机制：`_create_style_content()`首次切换时才执行
2. 数据恢复时机错误：项目打开时控件未创建
3. **关键缺失**：`_create_style_content()`末尾没有`after()`恢复逻辑

**修复**（学习世界观修复模式）:
```python
# _create_style_content() 末尾添加
if hasattr(self, '_style_profile') and self._style_profile:
    self.root.after(100, self._do_pending_style_restore)
```

### 5.3 业务逻辑误放GUI层

**现象**: `_add_style_to_tree()`方法有65行评分计算逻辑

**违规代码**:
```python
vocab_score = dims.get('vocabulary')
if vocab_score is None:
    if vocab and vocab.get('high_frequency_words'):
        vocab_score = min(10, len(vocab.get('high_frequency_words', [])) / 2)
```

**修复**（迁移到插件）:
- GUI: 调用`StyleLearnerPlugin.ensure_dimensions(profile)`
- 插件: 新增静态方法补充缺失评分

### 5.4 导出/导入数据不一致

**现象**: 导出风格后再选择，Treeview显示评分为默认5.0

**根因**: 插件生成的分析结果没有`dimensions`字段

**修复**:
1. 插件`_analyze_text()`返回前调用`_generate_dimension_scores()`
2. GUI加载旧JSON时调用`ensure_dimensions()`补充

### 5.5 FONT_SIZE_TEXT属性不存在

**现象**: 点击【创建模板】报错`AttributeError`

**根因**: GlassTheme类没有`FONT_SIZE_TEXT`常量

**修复**: 改为`GlassTheme.FONT_SIZE_NORMAL`
